## 第三步：把 USDT 換成 ETH

### 使用閃兌

閃兌適合想快速完成交易的人。選擇「從 USDT 到 ETH」，輸入希望支付的 USDT 數量，系統會顯示預計收到的 ETH 數量。

確認時不要只看畫面上的「0 費率」。你應該比較的是：

- 最終收到多少 ETH；
- 預估成交價格是多少；
- 是否有滑點；
- 交易前後帳戶餘額差異。

「0 費率」不一定代表最後換到的 ETH 數量一定比現貨交易多。兌換價格本身可能已經反映流動性、報價差或市場波動，最終數量才是比較重點。

### 使用現貨交易

如果你想自行設定買入價格，可以進入現貨交易，搜尋 **ETH/USDT** 或所在地區可用的 ETH 交易對。

常見訂單有兩種：

- **市價單**：按照當時市場上的可成交價格立即買入。
- **限價單**：設定自己可以接受的價格，等市場價格觸及後成交。

市價單操作簡單，但在行情快速變動或流動性較低時，實際成交價可能與下單前看到的價格不同。限價單可以控制價格，但不保證一定成交。

OKX 對掛單和吃單的定義，是根據訂單實際如何成交，而不是單純看你選了市價單還是限價單。市價單通常會直接吃掉訂單簿中的現有委託，因此多數情況下屬於吃單；限價單如果立即成交，也可能被視為吃單。

## 買 ETH 時，C2C、閃兌和現貨哪個比較划算？

沒有一種方法永遠最便宜，因為三者的成本來源不同。

### C2C：付款方式較靈活

C2C 可能顯示零交易費，但商家報價通常會包含自己的價格差。你要比較的是同一時間、同一支付方式下，支付多少法幣可以收到多少 USDT 或 ETH。

C2C 的優點是可以使用部分本地付款方式，也能自行選擇商家。缺點是訂單條件較多，付款資料需要仔細核對，部分買入訂單還可能有提幣或賣出限制。

### 閃兌：最省操作時間

閃兌適合想快速把已有的 USDT、BTC 或其他支援資產換成 ETH。它不需要新手理解訂單簿，幾步就能完成。

但如果你交易金額較大，最好先比較閃兌預覽頁面的到手數量與現貨訂單簿價格。差距不一定很大，但在市場波動明顯時，不能只看標示的費率。

### 現貨：價格控制最清楚

現貨交易適合定期買入、分批建倉或希望使用限價單的人。你可以看到委託價格、預估手續費和成交紀錄，之後也比較容易計算平均成本。

對新手而言，最簡單的做法是先用小額測試：

1. 先充值少量 USDT。
2. 查看 ETH/USDT 的即時報價。
3. 分別比較市價單和限價單的使用方式。
4. 買入少量 ETH。
5. 在資產頁面確認 ETH 餘額和實際扣款。
6. 再決定是否增加交易金額。

## 買到 ETH 後，應該放在 OKX 還是提到錢包？

如果你打算短期交易，ETH 放在交易所帳戶內通常比較方便，因為可以直接賣出或換成其他資產。

如果你打算長期持有，則應該了解交易所帳戶和自託管錢包的差異：

- 放在 OKX：登入後即可管理，適合交易和定期買入，但需要依賴平台帳戶安全。
- 提到外部錢包：私鑰由自己保管，控制權較高，但忘記助記詞或輸入錯誤地址可能造成永久損失。
- 提到硬體錢包：適合長期持有較大金額的人，但購買、備份和使用流程較複雜。

提幣時不要只看 ETH 主網。OKX 可能支援 Ethereum、Arbitrum、Optimism、Polygon 等不同網絡，但接收方錢包必須支援你選擇的網絡。網絡選錯，資產可能無法正常到帳。

提幣前建議做三件事：

1. 先確認接收錢包支援的網絡。
2. 先提取一筆小額測試。
3. 核對完整地址和網絡名稱，再提交大額提幣。

## OKX 買以太幣常見問題

### OKX 買 ETH 一定要先買 USDT 嗎？

不一定。若所在地區支援直接購買 ETH，可以使用快捷買幣或信用卡、銀行轉帳等方式購買。若直接購買入口不支援你的法幣，則可以先買 USDT，再透過閃兌或現貨交易換成 ETH。OKX 的直接購買頁面會根據地區和付款方式顯示可用選項。

### C2C 買幣真的零手續費嗎？

OKX 的 C2C 頁面可能顯示 0 手續費購買，但你仍然需要比較商家報價。商家可能把成本反映在買賣價差中，因此「零手續費」不等於總成本為零。

### 買 ETH 用市價單還是限價單？

想立即成交，可以使用市價單；想控制最高買入價格，可以使用限價單。市價單在快速波動期間可能出現較大的實際成交差異，限價單則可能一直沒有成交。新手可以先用小額測試，不要一開始就把全部資金放進單筆訂單。

### CASH20 是否等於買 ETH 可減 20%？

不能直接這樣理解。CASH20 是提供的註冊邀請碼，返佣或獎勵是否適用，取決於註冊頁面、地區、活動規則和帳戶條件。交易手續費也會按照 OKX 帳戶等級、交易對和成交方式計算。註冊時應查看頁面是否清楚顯示相關權益。

### 買 ETH 需要多少錢？

OKX 買幣頁面會根據你選擇的付款方式和交易對顯示最低金額。實際最低限額可能因法幣、地區、付款通道和商家而變化，因此不要把其他地區看到的最低購買金額當成固定規則。
